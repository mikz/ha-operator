# 0.5.0: native lights and external duration sources

Requires Home Assistant Core 2026.10.2 or newer. This candidate extends existing
resource workers and native policy admission; release acceptance is recorded
separately against the final package.

Native light resources support their source's actual on/off, brightness, color and
effect capabilities. Managed controls report independent source feedback. Bare ON
leaves native lighting defaults available; explicit supported light settings remain
intent until feedback confirms them. See [native lights](../native-lights.md).

Resource `manual_duration_entity` and native occurrence `duration_entity` reference
independently configured `input_number` or `number` entities with native duration
units. A finite positive value is sampled once at admission. Accepted absolute
expiry never changes when the parameter changes, and the existing Reason/native
trace records the sample. Fixed durations remain supported. Explicit manual expiry
parameters and externally submitted occurrence expiry keep their existing precedence.

Invalid duration sources reject new default-duration manual requests or decline
native occurrence admission without replacing accepted intent. STOP still acts,
using the source when valid or the fixed manual-duration fallback with explanation.
No duration-source watcher, timer engine or helper provisioning is added.

Before upgrading, save a native HA backup. Older packages do not understand light
resources or the new duration-source keys; prepare compatible configuration through
the supported forms or restore the matching pre-upgrade backup before a downgrade.
The configuration-entry major version remains 4. Before returning to 0.4, release
leases that contain new light targets and remove new light resources and duration-source
keys through the 0.5 forms, or restore the corresponding saved configuration and
runtime snapshot. Do not install older code over incompatible configuration.
Existing external entities and their other consumers remain independently owned.
