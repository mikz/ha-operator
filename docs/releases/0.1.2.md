# 0.1.2: Reliable native fan commands

Native fan controls and HomeKit send power, speed, and direction as separate
commands. Previously, a direction change could use stale off feedback and
replace a pending on request with off.

Fan admission now composes partial commands against the latest accepted,
unexpired manual intent inside the serialized writer. Selecting a direction
while off keeps the fan off and retains that selection for a subsequent on
command within the lease. Explicit off still supersedes pending on. Expiry or
release clears the selection; bare on then uses the configured default.

Selected settings are saved with the lease. They never replace reported device
state or count as airflow confirmation. Complete profile requests remain
explicit targets, and request-ID retries do not recompose or renew intent.
Existing snapshots remain readable. No configuration migration is required.

The isolated lab adds encrypted HomeKit commands for native and relay fans in
both command orders, combined characteristic writes, off supersession, and
restart with pending intent. Tests compare accepted intent, raw device state,
received HAP events, and the independent simulator journal. The release evidence
bundle records the exact archive, execution results, and validation limits.
