# 0.2.0 upgrade notes

This release replaces custom snapshot persistence with Home Assistant Store and
removes the Operator journal, trace options, `export_trace`, and `seed_intents`.
The six retained actions keep their request signatures and duplicate behavior.
Playwright browser traces remain lab artifacts.

Back up Home Assistant before upgrading. The entry migration retains configuration,
subentries, and entity IDs, then removes only its old snapshot and trace paths.
It imports no old runtime state. Desired controls use configured initial values,
policy controls start enabled, and resources start in observe mode. Old leases,
occurrences, modes, deadlines, and duplicate-request records are discarded.
Check these defaults and issue any reviewed commands before activating Live.

Later reloads restore state saved by native Store without replaying ON attachment
edges or extending expiry. A command response confirms runtime acceptance;
ordinary delayed persistence can lose recent changes on a crash. Runtime write
failures follow HA Store behavior without inhibiting actuation. Invalid setup or
unusable restored data still produces a setup error and Repair.

Native entities, Recorder history, Activity, logger, downloadable diagnostics,
and `explain` replace Operator trace collection. Existing observation controls,
STOP barriers, relay interlocks, source-only followers, and manual expiry remain.
Validation results accompany the release artifact.
